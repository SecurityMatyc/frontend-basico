# Evaluaciones de Front-End

Repositorio que reúne tres evaluaciones individuales de Front-End desarrolladas durante el **primer semestre de 2025** como parte del proceso formativo en desarrollo web.

## Autor

- Matías Gajardo

Las evaluaciones fueron desarrolladas individualmente como parte de las actividades académicas del curso.

## Descripción

El repositorio reúne ejercicios prácticos orientados a aplicar los fundamentos iniciales del desarrollo de interfaces web:

- Estructura semántica de páginas con HTML.
- Estilos y composición visual con CSS.
- Interacción básica mediante JavaScript.
- Primeros conceptos de diseño responsive.

## Contenido del repositorio

- Evaluación 1.
- Evaluación 2.
- Evaluación 3.

Cada evaluación contiene los archivos correspondientes al trabajo solicitado, incluyendo estructura HTML, estilos CSS y scripts JavaScript cuando corresponde.

## Tecnologías

- HTML
- CSS
- JavaScript

## Propósito y alcance

Este repositorio funciona como registro académico del aprendizaje inicial en desarrollo Front-End y como evidencia de la evolución de los fundamentos necesarios para construir interfaces web.

Por su naturaleza, corresponde a un conjunto de ejercicios introductorios y no a una aplicación destinada a producción.
