# 🎨 Evaluaciones de Front-End

Repositorio que reúne **tres evaluaciones individuales de Front-End** desarrolladas durante el **primer semestre de 2025** como parte del proceso formativo en desarrollo web.

Estas evaluaciones corresponden a **trabajos académicos básicos**, realizados mientras se aprendían los **fundamentos iniciales del desarrollo front-end**. Por esta razón, el objetivo principal de este repositorio es **conservar evidencia del proceso de aprendizaje y práctica temprana** en tecnologías de interfaz web.

Estas evaluaciones representan **una etapa inicial de aprendizaje**, donde se practicaban los conceptos fundamentales necesarios para comenzar a desarrollar interfaces web.
