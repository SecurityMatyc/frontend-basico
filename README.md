# Evaluaciones de Front-End

Repositorio académico que reúne tres evaluaciones individuales de Front-End desarrolladas durante el **primer semestre de 2025** como parte del proceso formativo en desarrollo web.

## Estado del proyecto

Colección introductoria de ejercicios prácticos. Cada evaluación se centra en aplicar progresivamente fundamentos de estructura web, estilos, interacción y diseño responsive.

El repositorio funciona como evidencia del aprendizaje inicial y no corresponde a una aplicación preparada para producción.

## Autor

- Matías Gajardo

Las evaluaciones fueron desarrolladas individualmente como parte de las actividades académicas del curso.

## Objetivos de aprendizaje

- Construir páginas con estructura HTML semántica.
- Aplicar estilos mediante CSS.
- Incorporar interacción básica con JavaScript.
- Comprender principios iniciales de diseño responsive.
- Organizar archivos de una interfaz web.
- Evolucionar desde páginas estáticas hacia experiencias interactivas.

## Contenido del repositorio

El repositorio reúne tres trabajos académicos:

- **Evaluación 1:** fundamentos de estructura y contenido HTML.
- **Evaluación 2:** composición visual y estilos mediante CSS.
- **Evaluación 3:** interacción básica y aplicación de JavaScript.

Cada evaluación contiene los archivos correspondientes al trabajo solicitado, incluyendo documentos HTML, hojas de estilo CSS y scripts JavaScript cuando corresponde.

## Tecnologías

- HTML
- CSS
- JavaScript

## Organización sugerida

Cada evaluación puede revisarse de manera independiente para observar la progresión de los contenidos y la aplicación de los conceptos trabajados durante el curso.

La estructura concreta de carpetas y archivos corresponde a la organización utilizada en cada entrega académica.

## Cómo revisar los ejercicios

Al tratarse de ejercicios Front-End sin un servidor backend obligatorio, pueden revisarse localmente de la siguiente manera:

1. Clonar el repositorio.
2. Ingresar a la carpeta de una evaluación.
3. Abrir el archivo HTML principal en un navegador.
4. Revisar los estilos y las interacciones implementadas.

También es posible utilizar una extensión de servidor local para visualizar correctamente los archivos y probar el comportamiento de JavaScript.

## Propósito y alcance

Este repositorio funciona como registro académico del aprendizaje inicial en desarrollo Front-End y como evidencia de la evolución de los fundamentos necesarios para construir interfaces web.

Por su naturaleza, corresponde a un conjunto de ejercicios introductorios. No incluye autenticación, persistencia de datos, API, backend ni una arquitectura destinada a producción.

## Posibles mejoras

Como continuación del aprendizaje, los ejercicios podrían evolucionar mediante:

- Diseño responsive más completo.
- Validaciones de formularios.
- Componentes reutilizables.
- Mejoras de accesibilidad.
- Integración con una API.
- Uso de herramientas de control de versiones y despliegue.
